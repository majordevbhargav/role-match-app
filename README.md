# Role Match App

An AI-assisted career matching application that helps users compare their profile with potential roles and explore how well their skills align with job opportunities.

## Overview

The project was built as a modern web application using React and TypeScript. It focuses on turning a user's skills and experience into a more useful role-discovery workflow.

## Features

- Candidate and role matching workflow
- Modern responsive interface
- Interactive application experience
- AI-oriented career matching direction
- Reusable React components

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Modern component-based frontend architecture

## Getting Started

```bash
git clone https://github.com/majordevbhargav/role-match-app.git
cd role-match-app
npm install
npm run dev
```

Open the local development URL shown by Vite.

## Development Notes

The repository can be edited locally with any modern IDE or through GitHub Codespaces. Keep secrets and service credentials outside the repository.
